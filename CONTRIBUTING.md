# Contributing

Contributions are welcome.

## Getting started

1. Fork the repository and create a branch.
2. Install dependencies and prepare the local database.
3. Run the tests before opening a pull request.

## Pull request expectations

- Keep changes focused.
- Add or update tests where appropriate.
- Document user-facing changes.

## Code style

The project uses Black, isort, Ruff, and mypy. Please run the relevant checks locally before submitting a PR.
